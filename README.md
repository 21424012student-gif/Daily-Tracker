# Daily-Tracker
Daily Tracker merupakan aplikasi web personal yang dirancang untuk membantu pengguna mengatur, memantau, dan menjalankan aktivitas harian secara lebih terstruktur. Aplikasi ini berfokus pada pengelolaan jadwal, pengingat waktu, serta pembentukan rutinitas dan kedisiplinan dalam menjalankan kegiatan sehari-hari.
